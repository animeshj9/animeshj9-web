# Animesh / Lab

The source for [animeshj9.com](https://animeshj9.com), a collection of small tools, models, and experiments by Animesh Jain.

## Structure

Each experiment lives one level below the domain in its own folder:

```text
dist/
  index.html          # Lab index
  long-arc/           # animeshj9.com/long-arc/
```

Simple experiments stay together in this repository. If an experiment grows into a substantial standalone product, it can graduate to its own repository later without changing this lab's role as the index.

## Experiments

- **Long Arc** — A local-first thesis notebook for ideas that take years to prove. Data is stored only in the browser.
